# DMDW Case Study: Employee Attrition Analysis

## About

This project analyzes employee data using data mining and machine learning techniques to predict employee attrition and identify patterns that may influence employee turnover.

## Technologies Used

- Python
- Django
- Pandas and NumPy
- Scikit-learn
- HTML, CSS, JavaScript
- SQLite

## How to Run

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser.
